# Design System

Visual direction:

- Black-space background
- Purple/blue neon
- Orbital cube
- HUD panels
- Glassmorphism
- Star field
- Roadmap as orbit map
- Model router as constellation
- OmniRouter as provider hub
- Website as cinematic command center
- Inspired by the GLM/Z.ai orbital cube prototype

Avoid:

- Casino trading UI
- Fake PnL
- Broker execution UI
- Retail trading app patterns

Color direction:

- Near black
- Deep charcoal
- Electric violet
- Cyber blue
- Soft lavender
- Muted HUD gray
