# Cross-Agent Context

All agents share context through repo-local `shared_context/` files.

Before work, all agents must read:

- `PROJECT_STATE.md`
- `AGENT_HANDOFF.md`
- `RUN_QUEUE.md`
- `SAFETY_CONTRACT.md`
- `MODEL_ROUTING.md`
- `DESIGN_SYSTEM.md`

After meaningful work, all agents must update `AGENT_HANDOFF.md`.

Final reports must include outcome, files changed, validation, safety confirmation, and next task.

Claude, Codex, GLM, Grok, Warp, Zed, VS Code, and ChatGPT all use the same contract.
