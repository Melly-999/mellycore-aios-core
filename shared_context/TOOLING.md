# Tooling

- Zed: fast editor-agent workspace for code navigation and local edits.
- VS Code: broadly compatible editor workspace and settings examples.
- Warp: safe terminal workflows, prompts, and repeatable operator runbooks.
- GitHub: remote repository, issues, PRs, review trail, and collaboration history.
- ChatGPT Project: strategy, prompt generation, planning, memory, and shared context upload.
- Claude Project: architecture, reasoning, docs, and review.
- Codex: implementation, validation, local git hygiene, and PR preparation when approved.
- GLM 5.2: cheap/dynamic worker for drafts, variants, and reference implementation ideas.
- Grok: critique, second opinion, and risk review.
- OmniRouter: provider/model routing hub and local gateway abstraction.
