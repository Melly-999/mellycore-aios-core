## Purpose

`shared_context/context_graph_fixture_001.json` is the first static, reviewable Context Graph fixture for MellyCore AIOS. It translates the current repo documentation, task reports, static showcase state, safety rules, and external-inspiration summaries into a compact graph model with clusters, nodes, edges, source references, and safety display flags.

## Scope

This fixture is data and documentation only. It is intended for review, future static rendering experiments, and future fixture-review tasks.

It does not implement:

- UI or frontend changes.
- Backend, API, database, or runtime ingestion.
- Obsidian, MCP, provider, or cloud integration.
- GitHub Pages, deploy, workflow YAML, or live preview publishing.
- Any live graph generation or automatic refresh.

## Static-Only Status

This fixture was not generated by a live graph engine. It is a hand-authored draft based on reviewed repo documents. Future agents should treat it as a proposed static snapshot, not as runtime truth.

The fixture must not be described as:

- Live telemetry.
- A production graph.
- A deployed graph service.
- A database-backed model.
- An automatically generated or continuously refreshed graph.

## Review Guidance

Future agents should review the fixture by checking:

1. Every node has a repo-backed `sourceRefs` entry.
2. Every edge has `evidenceRefs`.
3. Every safety/risk node is policy or status metadata only, not sensitive content.
4. Low-confidence external visual inspiration remains marked low or unverified.
5. No edge invents runtime, deploy, backend, API, database, MCP, Obsidian, provider, or live trading capability.
6. Any contradiction or stale-source concern is routed through `shared_context/CONTRADICTION_LEDGER.md` and a human review step.

## Schema Mapping

The JSON fixture uses the field names requested by `MELLYCORE-KNOWLEDGE-GRAPH-FIXTURE-DRAFT-001`:

- `cluster` maps to `ContextNode.cluster_id` in `shared_context/CONTEXT_GRAPH_SCHEMA.md`.
- `sourceRefs` maps to `ContextNode.source_refs`.
- `safeToDisplay` maps to the public metadata posture described by `SafetyDisplayState`.
- `evidenceRefs` maps to `ContextEdge.source_refs`.

The fixture intentionally omits raw file bodies and stores only reviewed summaries and repo-relative references.
