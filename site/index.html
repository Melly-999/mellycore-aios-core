Safety / Control Layer

Explicit safety constraints, visible at every layer. Safety is architectural, not decorative.

[#] No secrets [#] No keys [=] No unsupervised runs [+] No copied workspace
  • [x] No secrets in the repository.
  • [x] No real API keys committed.
  • [x] No provider tokens in tracked files.
  • [x] No environment secret values in version control.
  • [x] No destructive git operations without explicit approval.
  • [x] No publishing or hosting without explicit approval.
  • [x] No MellyTrade mutation from MellyCore AIOS.
  • [x] No wholesale import of the GLM workspace — reference only.
  • [x] No .git import from reference workspaces.
  • [x] No database files committed.
  • [x] No local runtime state committed.
  • [x] Static-first before any runtime integration.
  • [x] Honest validation — no fake status indicators.

The GLM/Z.ai workspace is reference only. No GLM files have been copied into this repository. Visual inspiration is acknowledged; wholesale import is forbidden.

MellyCore AIOS is standalone and separate from MellyTrade. This project contains no trading runtime, no broker connectivity, and no execution surfaces of any kind.
