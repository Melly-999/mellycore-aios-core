   product metaphor. The orbital routing core is a functional Control Plane
   overview with complete non-3D semantics, not a replacement hero.
2. **OmniRouter name vs current capability:** OmniRouter is routing-policy
   architecture metadata. No provider proxy, connection, or live route is
   implied.
3. **Historical NASA statements:** current positioning and the merged runtime
   retirement supersede the old live-NASA product claims. Historical reports
   remain historical.
4. **Existing contracts vs new entity needs:** AI Operations Intelligence and
   Operations Data Contract fields/status semantics remain authoritative.
   The new entity catalogue extends frontend concepts without designing a
   production database.
5. **Static UI vs future runtime:** existing `site/` modules are static evidence.
   Every Control Plane fixture/simulation/future placeholder receives a visible
   source mode.
6. **Stale living pointer:** the old unqualified OpenRouter "Current Exact Next
   Task" heading in `AGENT_HANDOFF.md` is explicitly historical, preventing two
   current-task claims.

No conflict blocked the core architecture.
